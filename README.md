# Four Rolls（暗房复刻 · 临时）

独立的单页 3D 体验，复刻“四卷胶卷 → 暗房 → 墙 → 信”的流程。不依赖个人网站，也没有构建步骤。

## 运行

```bash
python3 serve.py 4340
```

打开 http://127.0.0.1:4340 。`serve.py` 禁用缓存，改完代码直接刷新即可。

## 流程

1. **选卷桌**：四卷胶卷，点任意一卷进入；四卷都打开过之后，底部提示栏 “pick one” 右侧出现 “to the darkroom →”（和原视频一致，只在选卷桌出现，带发光和箭头提示）。
2. **Mature**：只需拖动拉出胶片，经过安全灯下的格子会自动显影。
3. **slow days**：点一格举到光前，移动指针让它倾斜；再点一次翻到背面，看贴在背后的手写纸条。
4. **far away**：拉拨杆随机洗到一张幻灯片，画面一开始是虚焦的；左右拖动（或滚轮、方向键）转动调焦轮。转动时标题提示 closer / further away，看片器顶上的小灯越近越亮，齿轮声音也越来越高。对准后落下邮戳：拍摄地点、当时相隔多少公里和一句话，右上角累计总公里数；每找到 6 张有一次里程碑。
5. **still us**：一叠照片，把最上面一张往右拖是“冲印”（红笔圈出，最多 6 张），往左拖是“收进盒子”；点任一堆最上面的照片可以拿回来。方向键也可以操作。
6. **看片台**：选中的底片摆在灯箱上，放大镜跟随指针，点击全屏查看；“change negatives” 打开选片面板，可以更换要冲印的底片。
7. **显影盘**：一个固定的暗房角落：瓷砖墙、墙上的安全灯、湿台面、透明药水的显影盘、相纸盒、棕色药瓶、计时器、晾绳。取一张相纸放进药水，左右拖动摇晃显影盘（液面会起波纹），计时器指针随显影走；显影完成后夹起滴水、挂上晾绳，照片带着水光慢慢晾干、往台面滴水；点挂着的照片读背面，全部晾干后画面里出现手写的 “all dry, → to the wall”。
8. **软木墙** → **信**（打字机逐字出现）→ “wind it back” 回到开场，形成闭环。

## 正反馈

- 所有声音都用 Web Audio 实时合成，不加载音频文件；右下角 “sound on/off” 可以静音，选择会记住。
- 关键时刻会落下一枚手写印章（`hud.toast`），并溅出暖色光点（`hud.burst`）：Mature 每显影 6 格及整卷完成、slow days 读到第 1/5/12/24 张纸条、still us 选出第一张和第六张及全部分完、看片台全部看过、每张照片显影完成、全部晾干。
- 软木墙开场时会汇总一路上的收获（冲印张数、显影格数、读过的纸条、累计公里）。

## 替换内容

- 文案、片名、slow days 背面纸条（`SLOW_NOTES`）、far away 地点和公里数（`FAR_PLACES`）、照片背面和信：`src/content.js`
- 真实照片：`frames` 里的 `photo` 填图片地址，竖幅居中裁成 3:4；横幅加 `wide: true`，按 4:3 横幅处理：在底片上横躺（和真胶卷一样），举起看、看片器、相纸、晾绳和墙上都是正的横幅。`photo` 为 `null` 时自动生成占位图；`wide` 标错时控制台会提示。
- 测试图：`TEST_PHOTOS` 指向 `photos/test10/`（10 张实拍的网页尺寸副本，已转正，不进 git），循环分配到四卷。

## 结构

- `src/stage.js` 渲染器、桌面、灯光、相机、拾取与拖拽
- `src/props.js` 道具：胶卷罐、胶片、笔、显影盘、药瓶、放大镜、看片机、灯箱
- `src/util.js` 占位图、统一照片着色器（负片 / 正片 / 相纸显影 / 黑白）、手绘圈和心
- `src/scenes/` 各场景
- `vendor/` 从站点 node_modules 拷贝的 three r186 与 gsap 3.15

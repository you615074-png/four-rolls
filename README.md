# Four Rolls（暗房复刻 · 临时）

独立的单页 3D 体验，复刻“四卷胶卷 → 暗房 → 墙 → 信”的流程。不依赖个人网站，也没有构建步骤。

## 运行

```bash
python3 serve.py 4340
```

打开 http://127.0.0.1:4340 。`serve.py` 禁用缓存，改完代码直接刷新即可。

## 流程

1. **选卷桌**：四卷胶卷，点任意一卷进入；四卷都看过后出现 “to the darkroom →”。
2. **Mature**：只需拖动拉出胶片，经过安全灯下的格子会自动显影（不再需要逐格点击）。
3. **slow days**：点一格举到光前，移动鼠标或手指让它倾斜，背光下显示正片和边码。
4. **far away**：按看片机的红色拨杆，一次换一格，顶部显示日期和片名。
5. **still us**：印样纸上用红笔圈要冲印的照片，换铅笔画心。
6. **看片台**：圈中的照片摆在灯箱上，放大镜跟随指针，点击全屏查看；看完出现 “now, let's print them →”。
7. **显影盘**：点相纸，放入药水里显影，挂上晾绳；点挂着的照片翻到背面读手写字；全部晾干后 “all dry, to the wall →”。
8. **软木墙** → **信**（打字机逐字出现）→ “wind it back” 回到开场，形成闭环。

## 替换内容

- 文案、片名、照片背面和信：`src/content.js`
- 真实照片：把 `frames` 里的 `photo: null` 改成图片地址（竖幅约 3:4）。为空时自动生成占位图。

## 结构

- `src/stage.js` 渲染器、桌面、灯光、相机、拾取与拖拽
- `src/props.js` 道具：胶卷罐、胶片、笔、显影盘、药瓶、放大镜、看片机、灯箱
- `src/util.js` 占位图、统一照片着色器（负片 / 正片 / 相纸显影 / 黑白）、手绘圈和心
- `src/scenes/` 各场景
- `vendor/` 从站点 node_modules 拷贝的 three r186 与 gsap 3.15

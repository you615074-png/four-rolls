# Four Rolls（暗房复刻 · 临时）

独立的单页 3D 体验，复刻“四卷胶卷 → 暗房 → 墙 → 信”的流程。不依赖个人网站，也没有构建步骤。

## 运行

```bash
python3 serve.py 4340
```

打开 http://127.0.0.1:4340 。`serve.py` 禁用缓存，改完代码直接刷新即可。

## 流程

1. **选卷桌**：四卷胶卷，点任意一卷进入；打开过 still us（或四卷都看过）后，右下角出现醒目的 “to the darkroom” 按钮。
2. **Mature**：只需拖动拉出胶片，经过安全灯下的格子会自动显影。
3. **slow days**：点一格举到光前，移动指针让它倾斜；再点一次翻到背面，看贴在背后的手写纸条。
4. **far away**：拉拨杆随机洗到一张幻灯片，画面一开始是虚焦的；左右拖动（或滚轮、方向键）转动调焦轮，对准后清晰并记入 “N OF 24 IN FOCUS”。
5. **still us**：一叠照片，把最上面一张往右拖是“冲印”（红笔圈出，最多 6 张），往左拖是“收进盒子”；点任一堆最上面的照片可以拿回来。方向键也可以操作。
6. **看片台**：选中的底片摆在灯箱上，放大镜跟随指针，点击全屏查看；“change negatives” 打开选片面板，可以更换要冲印的底片。
7. **显影盘**：取一张相纸（或点显影盘）放进药水，左右拖动摇晃显影盘，摇得越快显影越快；显影完成后带着水滴挂上晾绳，镜头跟着抬起；点挂着的照片读背面，全部晾干后出现 “to the wall”。
8. **软木墙** → **信**（打字机逐字出现）→ “wind it back” 回到开场，形成闭环。

## 替换内容

- 文案、片名、slow days 背面纸条（`SLOW_NOTES`）、照片背面和信：`src/content.js`
- 真实照片：把 `frames` 里的 `photo: null` 改成图片地址（竖幅约 3:4）。为空时自动生成占位图。

## 结构

- `src/stage.js` 渲染器、桌面、灯光、相机、拾取与拖拽
- `src/props.js` 道具：胶卷罐、胶片、笔、显影盘、药瓶、放大镜、看片机、灯箱
- `src/util.js` 占位图、统一照片着色器（负片 / 正片 / 相纸显影 / 黑白）、手绘圈和心
- `src/scenes/` 各场景
- `vendor/` 从站点 node_modules 拷贝的 three r186 与 gsap 3.15

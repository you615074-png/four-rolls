# Four Rolls

一份寄给你的包裹：拆开麻绳，先读最上面的信，再把四卷胶片一卷卷打开，最后进暗房把选中的照片冲出来、晾干、钉上墙。

浏览器里的单页 3D 交互体验，用 three.js 和 GSAP 写成，没有构建步骤，所有声音都用 Web Audio 实时合成。

> 仓库只包含代码，不含照片。克隆下来直接运行，每一帧都会显示程序生成的占位图；换成自己的照片见下文。

## 运行

```bash
python3 serve.py 4340
```

然后打开 <http://127.0.0.1:4340>。`serve.py` 关掉了缓存，改完代码刷新就能看到。任何静态服务器都可以，只是不能直接用 `file://` 打开（ES 模块需要 HTTP）。

## 体验流程

1. **桌上的包裹**：解开麻绳、掀开盒盖。
2. **开场的信**：信一行行写出来，读完沿折痕折好放回信封；盒子移开，四卷胶片聚到桌面中央。
3. **Mature**：向右拖出胶片，经过安全灯下的底片会显影成照片。
4. **slow days**：点一帧举到灯前细看，再点一下翻到背面，读贴在后面的手写便签。
5. **far away**：拉下拉杆随机换一张幻灯片，左右拖动对焦轮，对准后显示地点和当时相隔的公里数。
6. **still us**：拖动最上面一张照片，向右留着冲印（最多 6 张），向左收进盒子。
7. **看片台**：选中的底片铺在灯箱上，放大镜跟着指针移动，点一下全屏细看。
8. **暗房**：取一张相纸放进显影盘，左右拖动摇晃，影像浮现得更快；显影完成后夹上晾绳，晾干后点一张读背面。
9. **照片墙 → 收好**：照片钉上墙，再装进相袋，清单记下这次打开了什么；可以把包裹重新封好再拆一次。

每个场景左下角都有返回按钮，一次回到上一级：胶卷和看片台回到书桌，暗房回到看片台，照片墙回到暗房，结尾回到照片墙；在书桌上，如果是从别的页面点进来的，它会变成 “LEAVE”，回到那个页面。Esc 键和返回按钮作用相同（在书桌上不会离开页面），打开信时按 Esc 先写完、再折好。

桌上的笔记本（或右下角的 “用自己的照片”）通往 **寄件人后台**（`edit.html`），可以在浏览器里改信件、片名、背面的话，并上传自己的照片。内容保存在本机浏览器的 IndexedDB 里，不会上传到任何地方。

## 换成自己的内容

- **文案**：信、片名、便签、地点和公里数都在 `src/content.js`。
- **照片（推荐）**：打开 `edit.html` 直接上传，可以一次选很多张，从选中的格子开始按顺序填，一卷放满后接着放进下一卷；竖幅裁成 3:4，横幅按 4:3 处理。
- **照片（文件方式）**：把图片放进 `photos/`，再新建 `photos/local.js`：

  ```js
  export default [
    { photo: 'photos/my-photo-1.jpg', wide: false },
    { photo: 'photos/my-photo-2.jpg', wide: true }, // 横幅
  ];
  ```

  这些照片会循环分配给四卷胶片。`photos/` 整个目录都在 `.gitignore` 里，照片不会被提交。

## 代码结构

- `src/main.js`：启动、场景切换
- `src/stage.js`：渲染器、相机、灯光、拾取与拖拽
- `src/scenes/`：桌面与包裹、四卷胶片、看片台与暗房、照片墙
- `src/props.js`、`src/deskSet.js`、`src/darkroomSet.js`：道具与场景布置
- `src/util.js`：占位图、照片着色器（负片 / 正片 / 显影）、手绘标记
- `src/hud.js`、`src/sfx.js`：界面提示与合成音效
- `src/editor.js`、`src/store.js`：寄件人后台与本地存储
- `vendor/`：three.js r186 与 GSAP 3.15 的发行文件
